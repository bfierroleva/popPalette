# PopPalette

**An agent-based population genetics simulator, designed as a teaching tool.**

PopPalette simulates evolving populations individual by individual, so that the effects of the main evolutionary forces can be seen as they happen rather than only through equations. Each sampled allele is displayed as a colour channel, so changes in genetic composition can be followed visually across individuals, populations and generations. It was built in Unity (C#) as a personal project during the third year of my BSc in Biology at Universidad Rey Juan Carlos.

## Features

- **Evolutionary forces:** mutation, genetic drift, natural selection and migration.
- **Non-random mating:** several mating schemes, including true inbreeding (mating between related individuals).
- **Multiple populations** connected by migration.
- **Genomic structure:** individuals carry several chromosomes; the sampled loci are segments of genes and can undergo recombination.
- **Modular design:** components can be combined to build different scenarios.
- **Bilingual interface:** English and Spanish.
- **Data export** in GENEPOP format, for analysis with standard population genetics software.
