# popPalette #

An agent-based population genetics simulator, designed as a teaching tool.
popPalette simulates evolving populations individual by individual, so that the effects of the main evolutionary forces can be seen as they happen rather than only through equations. It was built in Unity (C#) as a personal project during the third year of my BSc in Biology at Universidad Rey Juan Carlos.

Features:
Evolutionary forces: mutation, genetic drift, natural selection and migration.
Non-random mating: several mating schemes, including true inbreeding (mating between related individuals).
Multiple populations connected by migration.
Genomic structure: individuals carry several chromosomes. The sampled loci are segments of genes and can undergo recombination.
Modular design: components can be combined to build different scenarios.
Data export in POPGENE format, for analysis with standard population genetics software.

A compiled demo showcasing a subset of the simulator's features is available in Releases.

Running from source
Clone this repository and open the folder in Unity Hub.
